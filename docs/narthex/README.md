# Narthex Section Documentation

This folder is the deep documentation of each legacy Narthex section, produced to drive the faithful re-port into Parvus Ordo. Each doc captures the section's roles, flows, Supabase data model, RLS, key algorithms, edge cases, and gotchas in enough detail to rebuild it. Every doc ends with an acceptance-criteria checklist plus port notes mapping the section onto the Parvus Ordo stack.

| Section | Acceptance criteria | Summary |
| --- | --- | --- |

| [Home / Dashboard](./home-dashboard.md) | 18 | Narthex has no standalone dashboard; the Home/Dashboard section is the authenticated shell — a pure role-based index redirect (/ → /lessons for teacher/admin, /my-lessons otherwise) plus the auth bootstrap (profiles + memberships reads), AuthGuard/RoleGuard gating, and the DashboardLayout/Sidebar chrome with a super-admin parish-override banner. |
